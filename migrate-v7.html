把原本的私人書稿搬過來

舊網站與 GitHub Pages 是不同網址，所以瀏覽器不會自動共用 localStorage / IndexedDB。請從舊版下載「完整 JSON（含照片）」後，在這裡匯入。

  1. 在原本 http://127.0.0.1:8765 開啟「備份與匯出」。
  2. 下載「完整 JSON（含照片）」。
  3. 回到這個頁面選擇剛下載的 JSON。
選擇舊版完整 JSON

會匯入章節、正文、原始初稿、素材、全書定位，並把章節照片帶到「照片回憶」。

匯入後，資料仍只存在目前瀏覽器。若你換手機或清除網站資料，仍需要重新匯入備份。
